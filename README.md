# Context X-Ray

SillyTavern 上下文成本审计工具。回答三个问题：这次请求发了多少 token、
里面都是什么、哪几条最贵。附带正则死规则与冲突检测、批量关闭。

## 功能

### 📊 上下文快照
每次生成后自动采集最终 payload，按预设 / 聊天历史 / 世界书 / 角色卡 / 
未识别五类分解 token，给出单项成本排行 Top 15。

### 📝 预设成本审计
扫描全部预设条目，按 token 降序排列启用项，统计禁用条目囤积体积。
可识别启用判定来源（prompt_order vs prompts.enabled）。

### 🌍 世界书详情展示
列出本轮激活的每一条世界书，显示：
- 触发方式（常驻 / 向量 / 关键词）
- 命中的主要关键词与次要关键词
- order / position / depth / 概率 / sticky / cooldown 等元数据
- 原始 token 与实际匹配 token 对比

### 🔧 正则审计与清理
**死规则检测**（分四级）：
| 等级 | 判定 | 默认勾选 |
|---|---|---|
| L1 | findRegex 为空 | 是 |
| L2 | 正则语法非法 | 是 |
| L3 | placement 为空数组 | 是 |
| L4 | findRegex 等于 replaceString | 否 |

**冲突检测**（按 placement 分组）：
- **完全重复** / **替换冲突**（高危）：相同匹配式，不同或相同替换
- **顺序覆盖**（中危）：A 的输出被 B 重新匹配
- **范围包含**（中危）：宽匹配可能覆盖窄匹配
- **位置竞争**（低危）：同 placement 下规则过多

### 🌸 悬浮窗界面
- 右下角 🌸 悬浮球，可拖拽，位置记忆
- 弹窗含五个标签页：全部 / 快照 / 世界书 / 预设 / 正则
- 与扩展面板数据完全同步，勾选状态双向联动
- 窗口可拖拽标题栏移动，支持最小化收起

## 写入范围

批量关闭是本扩展唯一的写入操作：
- 只修改 `extension_settings.regex[].disabled` 字段
- 不删除规则、不修改其他字段
- 不触碰角色卡内嵌 scoped 正则
- 不修改 `character_allowed_regex` / `preset_allowed_regex` 白名单

**五道安全闸**：
1. 逐条勾选候选（L1–L3 默认勾选，L4 需手动）
2. 导出备份 JSON（强烈建议，本地下载）
3. 二次确认（5 秒内点第二次，否则自动复位）
4. 内存撤销（执行后可一键还原，刷新页面失效）
5. 只改 disabled 状态（规则本体保留，随时可在酒馆界面开回）

## 使用

### 初次使用
1. 安装后按 Ctrl+Shift+R 刷新页面
2. 右下角出现 🌸 悬浮球
3. 发一条消息 → 快照自动采集
4. 点 🌸 打开悬浮窗，或用扩展面板

### 各功能启动
| 功能 | 触发方式 |
|---|---|
| 上下文快照 | 自动（每次发消息） |
| 世界书详情 | 自动（有激活条目时） |
| 预设审计 | 手动点「开始审计」 |
| 正则审计 | 手动点「开始审计」 |

### 批量关闭流程
1. 正则审计 → 检出死规则与冲突
2. 逐条核对，调整勾选（默认已选 L1–L3）
3. **先点「导出备份」**
4. 点「关闭选中项」→ 5 秒内再点确认
5. 刷新页面查看酒馆正则界面同步状态

## 备份与恢复

### 自动备份
点「导出备份」下载 `regex-backup-<时间戳>.json`，内含完整 
`extension_settings.regex` 快照。

### 手动恢复
F12 打开 Console，执行：

```js
// 1. 导入模块
const m = await import('/scripts/extensions.js');

// 2. 替换数据（把备份文件里的 regex 数组粘贴到这里）
m.extension_settings.regex = [
  // 从备份 JSON 的 "regex" 字段复制粘贴到这里
];

// 3. 保存
const s = await import('/script.js');
s.saveSettingsDebounced();

// 4. 刷新页面
location.reload();
